# T2Rhythm 5.5.498.1308 화면·통합 검증

Android API 29 에뮬레이터, 720×1280px·320dpi에서 실제 Compose/Media3 코드를 실행했습니다. 이미지는 공개 영상이 아닌 테스트 패턴과 합성 커버·곡 목록입니다. 추천 카드는 한국어 리소스로 실행합니다.

확인한 문제와 수정:

- 영상은 작은 카드 대신 기존 상단 커버 영역 전체를 채우고, 가장자리는 잘라 맞춥니다. 하단 그라데이션으로 제목·전환·조작부 가독성을 유지합니다.
- 추가 작업은 우측 상단 48dp 터치 영역에 고정하며 선택 가능한 조작 버튼 수에 포함하지 않습니다.
- 추천 카드의 큰 화살표와 헤더 아이콘을 18/24dp로 제한해 기존 Material 3 비율로 맞췄습니다. 좋아요·싫어요·재생을 한 카드 안에 유지합니다.
- 서랍의 목록 아이콘에 고정 크기를 지정하여 Material 3 ListItem의 내부 크기 계산 충돌을 제거했습니다. 팝업의 제목·안내도 부모 화면에서 선택한 언어를 따릅니다.
- 커버 터치가 스와이프 영역 뒤로 가려지던 경로를 공통 부모로 옮겼습니다. 중앙 더블 탭과 기존 좋아요 취소, 양쪽 이동은 같은 플레이어 상태를 사용합니다.
- 추천 새 세대의 평가 초기화와 이전 세대 보관을 실제 버튼 조작으로 검증합니다. 비동기 저장 중에는 중복 조작을 잠시 막습니다.

실행 환경의 YouTube CONNECT 403 때문에 실접속 다운로드 성공은 확인할 수 없습니다. 고정 버전 NewPipe 추출기는 기록된 공개 응답으로 별도 실행하며, 로컬 WebM/MP4 재생·재다중화도 검증합니다. 삼성 실기기의 갤러리와 Android API 37 실기기 런타임은 이 환경에 없습니다. 앱은 compile/target SDK 37로 빌드합니다.
