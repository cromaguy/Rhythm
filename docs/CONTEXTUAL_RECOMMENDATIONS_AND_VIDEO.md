# 상황 추천과 뮤직비디오

T2Rhythm 5.5.498.1308 기준입니다. [영구 보관·충전 중 분석·영상 저장·믹스 서랍](DURABLE_ADAPTIVE_PLAYER.md)에 최신 동작과 제한을 정리했습니다.

## 추천 데이터와 학습

기존 영구 청취 저널은 유지합니다. 시간대·요일·장르 전환·재청취 간격·완주율·빠른 스킵·최근 취향에 장소와 오디오 출력 맥락을 추가했습니다. 선호 아티스트/장르, 즐겨찾기, 추가 시점, 미청취 곡과 전체 PCM 분석의 음향 유사도도 사용합니다. 상황 신호는 충전 중 누적 SQLite 색인으로 갱신합니다. 화면은 원본 저널을 재분석하지 않고 저장된 요약과 모델을 읽습니다. 원본 기록은 계속 보관합니다.

추천은 다음 순서로 계산합니다.

1. 평생 선호와 최근 상황 신호를 구성합니다. 표본이 적은 신호는 완화하고 최근 취향에는 시간 감쇠를 적용합니다.
2. 20개 특징을 고정된 스키마로 만들고 기본 규칙과 기기 내부 로지스틱 학습 점수를 합칩니다. 학습 표본이 적으면 학습 점수 영향도도 낮춥니다.
3. 현재 곡과 사용자가 명시적으로 덜 추천한 곡을 제외합니다. 아티스트·장르 반복을 줄이고, 기본 15%의 발견 순서에는 미청취 곡을 우선합니다.
4. 홈에서 제시한 목록·순서·특징·예측을 기록합니다. 이는 UI에 목록을 구성한 기록이며 실제 화면 응시를 측정하는 지표는 아닙니다.
5. 추천 특징을 제시한 곡의 실제 재생 구간 비율과 명시적 피드백을 저장하고, 충전·유휴 상태에서 가중치를 갱신합니다. UI 선택과 재생 시작은 구분해 기록하며, 단순한 자동 재생을 사용자의 명시적 선택이라고 표시하지 않습니다.
6. 해당 반응을 학습하기 **전** 예측의 Brier 오차를 기록합니다. 고정 확률 0.5의 기준 오차와 함께 표시합니다. 표본은 추천 선택·피드백에 치우칠 수 있으며 더 많은 데이터가 언제나 더 좋은 추천을 보장하지 않습니다.

플레이어의 추천 조정 버튼은 **더 추천 / 덜 추천 / 이 곡 선호 초기화**를 제공합니다. 초기화는 해당 곡의 명시적 선호를 지우며 과거 학습 이벤트를 삭제하는 기능은 아닙니다. 기본 규칙의 `context`, `learning`, `exploration` 가중치는 기존 스키마 1 JSON 가져오기/선택적 규칙 업데이트에서도 지정할 수 있습니다. 실행 코드는 내려받지 않습니다.

`music_metadata/recommendations/*.jsonl`은 영구 원본입니다. 중복 이벤트 ID는 다시 학습하지 않으며 모델은 원본에서 재구성합니다. 추천 제시와 반응의 특징·예측·알고리즘 이름을 남기므로 추후 다른 알고리즘으로 같은 기록을 다시 분석할 수 있습니다. 최근 선택 정보도 프로세스 재시작 후 복구합니다. 월별 기록에는 출력별 청취 시간과 장소 그룹 수를 표시합니다.

## 위치와 오디오 출력

설정 → 내 음악 보관함 → 청취 경험에서 위치 기록을 켭니다. 기본은 꺼짐이며, 대략적 위치와 **정밀 위치를 별도로 선택**합니다. Android 권한을 거절해도 음악과 추천은 동작합니다.

새 위치는 앱이 보이는 동안만 요청합니다. 백그라운드 위치 권한을 요청하지 않으며 앱이 보이지 않을 때 계속 위치를 추적하는 기능은 아닙니다. 15분보다 오래되거나 정확도가 너무 낮은 위치는 사용하지 않습니다. 대략적 모드는 좌표를 약 1km 격자로 묶습니다. 정밀 모드에는 허용된 좌표·정확도·고도·속도·방향·제공처를 남기되, 제공되지 않은 값은 만들지 않습니다. 추천의 장소 그룹은 정밀 모드에서도 격자를 사용합니다. 위치가 없을 때에는 직접 입력한 현재 장소 이름을 이용할 수 있습니다.

출력은 기기 스피커·유선·블루투스·USB·캐스트를 구분합니다. 연결된 기기의 제품 이름·샘플레이트·채널·인코딩 목록, 시스템 음악 볼륨과 최대 볼륨, 충전 여부·배터리 잔량도 기록합니다. 오디오 능력 목록은 연결 기기의 지원 능력이며 실제 디코더가 사용하는 샘플레이트를 뜻하지 않습니다. 추천에서는 출력 종류와 사용 가능한 연결 기기 이름을 함께 묶어 서로 다른 이어폰의 선호를 구분합니다. 실제 활성 기기를 확정할 수 없는 경로는 이 구분도 추정값입니다. 현재 출력 경로는 Android 시스템 경로와 오디오 상태로 **추정**하고 연결 기기 목록과 구분해 저장합니다. 블루투스 MAC 주소는 수집하지 않습니다. 맥락이 바뀌면 청취 구간을 나눕니다.

위치·기기 정보와 청취 기록은 앱이 서버로 업로드하지 않습니다. 사용자가 지정한 영구 백업 폴더에는 이 정보가 포함됩니다.

## 영상 보기

Expressive 플레이어의 제목 아래 음악/영상 전환을 누릅니다. 영상 연결과 관리 기능은 기존 더보기 메뉴에서 엽니다. 기본은 **무음 영상 + 기존 음원 유지**입니다. 가사를 보거나 화면을 떠나면 별도 영상 플레이어를 계속 실행하지 않습니다. 영상이 활성화된 동안 기존 Canvas 애니메이션 재생을 멈춥니다.

- **YouTube 후보 찾기**: 곡의 아티스트와 제목으로 후보를 검색하고 사용자가 선택합니다. 자동으로 정답이라고 단정해 연결하지 않습니다. 검색 실패 시 YouTube 검색과 직접 링크 입력을 제공합니다. 외부 사이트의 응답·차단·임베드 허용 여부에 따라 이용 가능성이 달라집니다.
- **링크 추가**: 검증된 YouTube 영상 ID를 연결합니다. NewPipeExtractor로 최대 720p·30fps의 영상 전용 스트림을 저장하고 기존 네이티브 플레이어로 재생합니다. WebM을 우선하고 파일당 96MB로 제한합니다. 기본은 Wi-Fi이며 관리 화면에서 모바일 데이터 사용을 선택할 수 있습니다. 접근 제한을 우회하지 않습니다.
- **파일 추가**: 문서 선택기로 영상 파일을 골라 앱 보관함에 복사합니다. 지원되는 비디오 트랙만 리먹싱해 오디오 중복을 제거합니다. VP8/VP9는 실제 WebM, 다른 지원 코덱은 MP4입니다. 확장자만 바꾸거나 H.264를 WebM이라고 저장하지 않습니다. 짧은 WebM 등 플랫폼 리먹싱 결과가 더 커지는 경우, 형식이 확인된 더 작은 호환 원본을 보관합니다. 이 경우 원본에 오디오가 남을 수 있지만 재생은 무음입니다. 디코딩/재인코딩으로 화질을 낮추는 기능은 아니므로 원본 대비 항상 크게 작아지는 것은 아닙니다.
- 영상 트랙·코덱 설정·시간 기준의 SHA256으로 중복 영상을 공유합니다. 직접 추가는 최대 1GB이며 공간이 부족하거나 암호화/지원하지 않는 트랙은 적용하지 않습니다.
- 음원의 진행 위치를 참고해 영상을 맞추고, 관리 창의 ±5초 버튼으로 인트로 차이를 보정합니다. 네트워크 버퍼링을 포함한 프레임 단위 동기화를 보장하지는 않습니다.

영상 연결을 해제해도 공유 영상 파일은 복구를 위해 남겨둡니다. 해제 상태는 기록으로 저장해 백업에도 반영합니다. 연결 JSON과 영상 파일은 `music_metadata/videos/`에 일반 파일로 보관합니다.

## 이미지

수집한 곡·앨범·아티스트 아트와 직접 지정한 아트는 공통 WebP 저장 경로를 사용합니다. 일반 저장은 최대 1600px, 품질 86이며 투명도를 지원하고 동일한 인코딩 결과는 SHA256으로 공유합니다. 원본 아트워크 모드의 추출 캐시는 WebP 품질 100을 사용합니다(지원 Android 버전에서는 무손실 인코딩). 초대형/변환 실패 아트와 기존 파일에는 호환 경로를 유지합니다.

음원 원본의 정확한 롤백을 위해 기존 이미지 바이트도 별도 보관합니다. MP4 커버 및 외부 플레이어 호환성을 위해 **음원 내장** 시에는 필요한 JPEG/PNG 바이트로 변환하며, 앱에 저장하는 표시 이미지는 WebP입니다. 앱 내부 원본 JPEG/PNG는 보존합니다. 외부 백업 사본만 원본 바이트를 담은 `.t2art`로 바꾸고 검증한 뒤 기존 이미지 사본을 제거하여 갤러리에 나타나지 않게 합니다.

## 업데이트

앱 화면과 백그라운드 확인 모두 `tak2-08/T2Rhythm`의 **태그**를 비교합니다. 한국어 릴리스 제목을 버전 숫자로 읽지 않습니다. 설치한 일반/Debug 패키지와 지원 ABI에 맞춰 실제 `T2Rhythm-버전.apk` 자산을 선택합니다.

다운로드는 릴리스의 SHA256, 파일 크기, 재개 바이트 범위, APK 패키지·버전·서명을 검증합니다. 크기가 달라도 무시하고 설치하는 경로는 제거했습니다. 검증 정보가 없는 배포물은 앱 내 설치 대신 브라우저 안내를 제공합니다. 검증한 파일은 설치 직전과 프로세스 재시작 후에도 다시 확인합니다. 설치창을 취소했거나 알 수 없는 앱 설치 권한 설정을 거쳐 돌아와도 파일을 유지해 재시도할 수 있습니다. 구형 Android에서 서명 정보를 읽는 호환 경로도 검증합니다. 설치창 실행을 설치 성공이라고 취급하지 않습니다. 다음 실행에서 설치된 버전이 다운로드한 버전에 도달했을 때 완료 상태를 정리하며 APK 자체를 즉시 삭제하지 않습니다.

Android의 설치 승인과 Play Protect 판단은 앱이 우회하지 않습니다. 네이티브 기능 변경은 APK 업데이트가 필요하며 기존 지원 JSON 규칙의 데이터 변경과 구분합니다.

## 청취율·날씨와 개인화 재생 흐름

재생마다 실제로 들은 음원 구간을 합칩니다. 탐색으로 건너뛴 구간은 청취한 것으로 계산하지 않으며, 되감아 같은 구간을 반복해도 전체 청취율을 중복 합산하지 않습니다. 속도를 고려한 음원 시간과 실제 청취 시간을 함께 보존합니다. 길이를 알 수 없으면 청취율은 알 수 없음으로 둡니다. `play` 원본 기록은 재생별 요약이고, 월별 곡 통계에는 각 재생에 같은 가중치를 준 평균 청취율을 표시합니다. 마지막 위치가 곡 끝이라는 이유만으로 완청이라고 학습하지 않습니다.

날씨 기록은 위치와 별도로 기본 꺼짐입니다. **Open-Meteo**의 API 키가 필요 없는 무료 공개 API를 사용합니다. Open-Meteo 소스는 공개되어 있지만 호스팅 API의 이용 한도와 이용 조건은 존재합니다. 앱이 무제한 조회를 보장하는 것은 아닙니다. 정밀 원본 좌표 대신 약 0.02도 지역으로 조회하고, 조회 간격은 최소 15분, 같은 지역 정상 갱신은 30분입니다. 온라인에서 허용된 새 위치와 날씨를 요청하고 실패 시 이전 값의 시각·지역이 유효한 경우만 사용합니다. 90분 이상 오래된 날씨를 과거 재생에 임의로 붙이지 않습니다. 날씨는 제공처의 현재 모델 기반 값으로 기상 센서 실측이라고 표시하지 않습니다. 기온·체감 기온·습도·강수·구름·바람·기압·날씨 코드·낮/밤·제공 시각과 조회 시각을 저장하며, 날씨별 장르·청취율 선호를 추천에 사용합니다. 제공처와 자료 출처: https://open-meteo.com/ / https://github.com/open-meteo/open-meteo (AGPL-3.0).

홈의 **나를 위한 음악**은 현재 시간대 믹스, 장르별 데일리 믹스, 14일 이상 안 들은 곡의 재발견, 현재 곡과 닮은 음악, 좋아요 곡의 장르 필터, 반복 감소 재생을 제공합니다. 기기의 음악과 기록으로 만들며 서버의 협업 필터링이나 새 발매 음악을 생성하는 기능은 아닙니다. 생성 결과를 바로 재생하거나 기존 재생목록으로 저장할 수 있습니다. 시간대 믹스는 시간마다 재계산하고, 새로 열 때 현재 맥락을 사용합니다. 태그 기반 장르 묶음은 신경망 클러스터라고 표현하지 않습니다. 추천에서 30일 쉬기와 영구 제외는 개인 믹스·자동 추천에 적용하고, 원본 파일·직접 재생하는 큐·블랙리스트와 구분합니다. 내 음악 보관함의 기록 설정에서 제외를 해제합니다.

기존 셔플과 별도로 반복을 덜하는 흐름을 선택할 수 있고, 플레이어 메뉴의 맞춤 곡 섞기는 기존 곡의 상대 순서와 현재 재생을 유지하면서 세 곡마다 새 추천을 삽입합니다. 맞춤 자동 이어듣기는 기본 꺼짐이며, 켠 경우 재생 서비스가 큐 끝에서 내 라이브러리의 유사곡으로 이어갑니다. 반복 모드, 사용자 일시정지·새 큐와 청력 보호 중단을 우선합니다.

기본 오디오 분석에 BPM·키 추정과 신뢰도를 추가했습니다. 곡 전체의 원본 지문·파형·음향 분석은 유지하며, BPM의 리듬 요약은 최대 20분으로 메모리를 제한합니다. 정렬에서 정보가 부족하면 기존 순서를 유지합니다. 음향 특징과 최근 청취·청취율·스킵으로 가중 평균 취향 벡터를 구성하고 로컬 코사인 유사도로 추천을 보완합니다. 이는 DSP 특징 벡터이며 CLAP 등의 신경망 임베딩이 아닙니다. 가사 의미 검색·텍스트 AI 재생목록·음성 DJ는 포함하지 않습니다. 기존 충전·유휴 분석 조건을 유지합니다.

미니 플레이어는 **T2Rhythm** 스타일, 전체 플레이어는 **Expressive**로 고정했습니다. 다른 테마 선택은 설정·온보딩·검색에서 제거하고 이전 저장값도 고정된 테마로 전환합니다. 아트워크 위 세 버튼을 제거해 이미지·영상 영역을 비우고, 제목 아래 음악/영상 전환을 둡니다. 영상 관리·추천 조정·맞춤 큐 기능은 기존 더보기 메뉴로 이동했습니다. 기본 홈에서 개인화를 먼저 보여주되 사용자가 직접 정한 섹션 순서는 유지합니다.

## 화면·소리 맥락과 추천 플레이리스트 평가

화면 밝기는 Android의 시스템 설정값과 자동 밝기 여부를 남깁니다. 실제 패널의 휘도(nit)를 측정한 값은 아닙니다. 시스템 음악 볼륨·최대 볼륨·앱 재생 볼륨, 기존 음원 음향 정보와 함께 밝기·음량별 청취율과 장르 선호를 추천에 반영합니다.

주변 소리 측정은 **기본 꺼짐**이며 별도 마이크 권한과 설정이 필요합니다. 앱이 보이는 동안 1분마다 약 1초를 측정하고, 원음은 메모리에서 수준 계산에만 쓰며 파일로 저장하거나 전송하지 않습니다. RMS·피크 dBFS·클리핑 비율·측정 시각·입력 소스·음악 재생 여부만 남깁니다. 화면을 떠나거나 설정을 끄면 측정을 중단합니다. 마이크가 차단되거나 입력을 얻지 못하면 정보 없음으로 처리합니다. dBFS는 기기 감도·입력 처리·스피커 음악에 영향을 받으므로 보정된 소음계의 dB SPL이라고 해석하지 않습니다. 3분보다 오래된 수준을 현재 맥락에 쓰지 않습니다. 주변 입력 수준별 장르와 실제 청취율의 관계도 추천 특징에 포함합니다. 새 모델 스키마 4는 이전 스키마 1~3의 13/14/17개 특징과 원본 이벤트를 보존하고 이동·낮밤·독립 선호를 추가합니다.

홈의 추천 플레이리스트 카드에는 표지·믹스 이름·곡 수·재생과 **좋아요/싫어요**를 묶었습니다. 같은 반응을 다시 누르면 취소하고 다른 반응을 누르면 전환합니다. 평가 당시 곡 목록과 평균 추천 특징을 원본으로 저장합니다. 믹스 평가와 개별 곡의 좋아요·제외는 구분합니다. 평가를 취소하거나 바꾸면 충전 중 모델을 원본에서 다시 구성하여 해당 믹스의 최신 유효 의도만 직접 학습합니다. 과거 평가 이력과 실제 재생 반응 기록은 남습니다. 새로 제안하는 믹스 종류에도 평가를 사용합니다. 이전 믹스의 평가도 청취 기록 설정에서 취소·전환할 수 있습니다.

추천 영역의 위치 변경 버튼은 기존 홈 섹션 편집기로 연결합니다. 둘러보기를 포함한 모든 표시 섹션의 위치·표시 여부를 사용자가 직접 정할 수 있고, 명시적으로 선택한 순서는 앱을 다시 시작해도 유지합니다. 추가 믹스 종류는 펼쳐보는 영역으로 옮겨 추천 카드의 주 기능과 구분했습니다. 일반 ExoPlayer 셔플이 켜져 있을 때는 맞춤 큐 삽입 전에 셔플을 끄도록 안내합니다. 임의의 셔플 타임라인에 잘못된 인덱스로 삽입하거나 현재 재생을 재시작하지 않습니다.
