# 5.5.498.1306 플레이어·알림 수정

실제 커버가 있는 배경 모드에서 아트워크 영역이 숨겨지면 기존 영상 상태와 관리 창도 함께 사라졌습니다. 영상 세션과 대화상자를 플레이어에 독립적으로 두고, 영상 선택 시 해당 영역을 표시합니다. 가사 보기·배경 모드에서도 영상 관리 경로가 유지됩니다. 영상은 기존처럼 무음이고 기존 음악 재생은 유지합니다.

추가 작업(세 점)은 우측 상단의 고정 48dp 버튼입니다. 음질 표시와 겹치지 않으며 하단 버튼 목록·편집·5개 제한에서 제외합니다. 이전 MORE 저장값은 제외하고 나머지 순서/숨김 설정을 유지합니다. 일반 모드는 고정 가사/좋아요 2개와 선택 3개, 통합 모드는 선택 5개를 지원합니다.

선택적인 온라인 아트 조회는 초기 라이브러리 준비 알림의 진행/완료 조건에서 제외합니다. 이전 실행에서 남은 진행 알림과 취소한 작업 알림을 정리합니다. 음원별 자동 조회에는 동시 중복 방지·6시간 재시도 간격·45초 제한을 두고 자동 실패 토스트는 표시하지 않습니다. 명시적인 수동 조회는 유지합니다.

사용자가 제공한 1304 로그의 문구는 기존 실험실의 강제 테스트 크래시 함수와 일치합니다. 해당 버튼·검색 항목·함수를 제거하고 정상적인 실제 오류 보고는 유지합니다. 이는 특정 Samsung/Android 버전의 임의 오류라고 판단한 수정이 아닙니다.

회귀 검증에는 실제 커버+배경 모드 영상, 아트워크 미표시 상태에서 관리 창, 5개 조작 버튼과 고정 상단 버튼, 저장값 이관, 이전 알림 정리와 준비 완료/취소 흐름을 포함합니다. 실제 Android 17 제조사 기기와 YouTube 온라인 재생은 별도 검증이 필요합니다.
