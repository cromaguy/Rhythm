`youtube-cc-fixture.json.gz` contains the nine unmodified JSON request/response
objects from NewPipeExtractor v0.26.5's `CCLicensed` stream-extractor test,
compressed together solely for offline integration testing. It is not bundled
in the APK and does not download or bypass access to a live video.

Source: https://github.com/TeamNewPipe/NewPipeExtractor/tree/v0.26.5/extractor/src/test/resources/mocks/v1/org/schabi/newpipe/extractor/services/youtube/stream/youtubestreamextractordefault/cclicensed
